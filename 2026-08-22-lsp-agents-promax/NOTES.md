# Execution log & protocol amendments

Companion to PLAN.md — what actually happened and every deviation, so results are interpretable.

## 2026-08-22/23 — Phase 0/1 bring-up

- **Serving**: pip vLLM (no aarch64 wheels), pip SGLang (sm100 cubins missing GemmaRMSNorm
  for sm_121; triton ptxas too old for sm_121a) both failed on the GB10. Working stack:
  `serving/spark-sglang/` (vendored MiaAI-Lab/Qwen3.8-27B-SGLang-DGX-Spark), image
  `lmsysorg/sglang:qwen38-27b`, `QUANT=fp8` (official Qwen/Qwen3.8-27B-FP8), DSpark
  speculative decoding, port 8888, served name `qwen3.8-27b-sglang`,
  `MAX_CONCURRENT_REQUESTS=8`. Measured: 31.7 tok/s single-stream short-context code;
  ~14–15 tok/s per-stream at 3 concurrent with 40k-token contexts.
- **Protocol deviations from the paper** (documented, applied to ALL arms):
  temperature 1.0 / top_p 0.95 / top_k 20 (model-card thinking defaults; paper doesn't
  state temperature), `reasoning_effort: medium` (xhigh default overthinks), max_tokens
  16384/step, `MSWEA_COST_TRACKING=ignore_errors` (cost cap meaningless locally; step cap
  300 enforced), mini-swe-agent **v2.4.6** (tool-calling variant, `swebench.yaml` default).
- **Gold gate**: albumentations-2337 golden patch → SUCCESS via harness on worker-a (42s).
- **Env-flaky instances** (golden fails on our LAN): `stanfordnlp__dspy-9193`,
  `huggingface__transformers-38788`. Root cause (likely): several images bake in an
  unreachable ByteDance proxy (`sys-proxy-rd-relay.byted.org`) → all in-container network
  fails. Harness excludes golden-failed instances from the denominator automatically.
- **Smoke (arm A config, albumentations-2337)**: Submitted at 80 steps / 78 min → RESOLVED.
- **dev-10 shakeout** (one instance per language + extras, arm A): 3/9 resolved on
  golden-valid instances (maven ✓, cli ✓, s2n-tls ✓); 8/10 submitted; 2 hit the 300-step
  cap with empty patches. dev-10 instances overlap stage sets — dev results are for
  debugging only, not headline numbers.
- **Disk lesson**: 29 python images don't fit worker-a (verl image bundles CUDA libs).
  All runs use `agent/run_batch_waved.sh`: NAS-cached load → rollout → eval → evict, waves
  of 4–6. Eval always grades in the ORIGINAL key4127 images regardless of arm.
